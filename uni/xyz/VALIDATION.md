# UNI.XYZ validation contract

Every test produces an expected result, observed result, evidence receipt, and disposition.

## Executed locally

- Sixteen independent A/B configurations.
- Four expected-versus-observed classifications.
- BREATHE.IN and BREATHE.OUT boundary receipts.
- Denied-command non-mutation.
- Authorized reaction with effect receipt.
- Post-reaction REST assimilation.
- Measured Particle, Gas, Liquid, and Solid reference classifications.
- Five independent Lionheart failure gates.
- Big Brother observe-only behavior.
- Phoenix command-only boundary.
- ChromeOS/Bootstrap, Windows, Android, and Phoenix semantic round-trips.
- Lifecycle rejection of direct promotion.
- Schema rejection of denied-authority mutation, null authorized receipt, classification mismatch, missing OUT exchange, label-only phase, and approval without authority.

Run `npm test` and `npm run evidence` to reproduce the evidence.
